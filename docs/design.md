## 1. システム概要

CLIライブラリは、デバッグや実装支援を目的とするユーザーインターフェースとして設計されています。

組み込み機器等の資源に制約がある環境においても、利用者が必要とするコマンド（プログラム）を登録しておけば、所定のタイミングでコマンドを実行する「実行基盤」として動作します。

「実行基盤」の役割と同時に、コマンドラインの管理をはじめ、履歴保存、TAB補完（対応予定）、中断要求等の機能をサポートしています。

また、CLIライブラリが消費するメモリ使用量は利用者がコントロールすることができます。
- 動的メモリは使用しない
- バッファ等の資源を大きく消費するようなデータは利用者が消費サイズの指定を行う

そのため、少ないメモリ資源でも必要以上にリソースを消費することなく動作が可能なソフトウェアとなります。

## 2. 機能概要
### 2.1 機能一覧

CLIライブラリは、ユーザが定義したコマンドラインを解析し、対応するハンドラーを呼び出すことでコマンドの開始を要求します。

コマンドの処理内容や処理継続・終了条件は利用者が負う責務とし、CLIライブラリでは処理内容や稼働状態を管理しません。

コマンドの実行期間中は新たなコマンド入力を制限し、キャンセル等による停止要求をユーザへ通知します。
- コマンドラインの作成・編集
- 履歴保存機能
- コマンド登録・解除
- コマンド実行管理


### 2.2 主要ユースケース

ターミナルソフトウェアが利用可能なPCと、CLIが利用可能な組み込み機器が接続されている環境を想定しています。

- ターミナルソフトを使用する場合の構成例

```text
    ┌─────────────────────┐                ┌─────────────────────┐
    │   ターミナル等のコンソール画面           │  コマンド入力  │    組み込み機器                          │
    │   （Windows OSで動作）                   │───────→│    - CLI制御                             │
    │                                          │                │    - 入出力データ管理                    │
    │  ┌─────────────────┐  │ コンソール画面 │                                          │
    │  │CLI Library [v0.0.1]              │  │    更新出力    │                                          │
    │  │> _                               │  │←───────│                                          │
    │  └─────────────────┘  │                │                                          │
    └─────────────────────┘                └─────────────────────┘
                          ↑　
                          │
                          │キー情報はPCを介して組み込み機器に渡される
                          │
    ┌──────────┴──────────┐
    │   キーボード（入力デバイス）             │
    └─────────────────────┘
```

## 3. アーキテクチャ
### 3.1 システム全体構成

CLIライブラリは、ソフトウェアのデバッグや実装支援を目的とした組み込み向けのシステムです。

ユーザが定義したコマンドを使用することでアプリケーションの操作や、状態監視を実現します。

- システム構成図

```text
    ┌──────────────────────────────────────────────────┐
    │   Application                                                                                      │
    │  ┌────────────────────┐        ┌────────────────────┐  │
    │  │- ユーザアプリ                          │        │- ユーザ定義コマンド                    │  │
    │  │                                        │        │  （CLIに登録するコマンド）             │  │
    │  └────────────────────┘        └────────────────────┘  │
    └──────────────────────── ↑ ────────────────────────┘
                                                       │ API呼び出し
    ┌──────────────────────────────────────────────────┐
    │   Middleware                                                                                       │
    │  ┌──────────────────────────────────────────────┐  │
    │  │- CLIライブラリ                                                                             │  │
    │  │  - メインプロセス                                                                          │  │
    │  │  - コマンド機能                                                                            │  │
    │  │  - 入出力インターフェース                                                                  │  │
    │  │    - キー入力                                                                              │  │
    │  │    - コンソール更新                                                                        │  │
    │  └──────────────────────────────────────────────┘  │
    └──────────────────────── ↑ ────────────────────────┘
                                                       │ 入出力インターフェースと接続
    ┌──────────────────────────────────────────────────┐
    │   Driver                                                                                           │
    │   - 通信機能                                                                                       │
    └──────────────────────────────────────────────────┘
                                                       ↑
    ┌──────────────────────────────────────────────────┐
    │   Hardware                                                                                         │
    │   - MCU                                                                                            │
    │   - コンソール画面（Windows OS）                                                                   │
    └──────────────────────────────────────────────────┘
```


### 3.2 ソフトウェア構成

本ソフトウェアは、ハードウェアの依存度を排除し、再利用性と保守性を高めるために階層化アーキテクチャを採用しています。

CLIライブラリは`Middleware層`に位置するソフトウェアとして構成されています。

- ソフトウェア構成図

```text
    ┌──────────────────────────────────────────────────┐
    │   Application                                                                                      │
    │  ┌────────────────────┐        ┌────────────────────┐  │
    │  │- ユーザアプリ                          │        │- ユーザ定義コマンド                    │  │
    │  │                                        │←───│  定義内容によって、アプリの操作が可能  │  │
    │  └────────────────────┘        └────────────────────┘  │
    └──────────────────────── ↑ ────────────────────────┘
                                                       │ API呼び出し（CLIメインプロセスの実行・コマンドの登録）
    ┌──────────────────────────────────────────────────┐
    │   Middleware                                                                                       │
    │  ┌──────────────────────────────────────────────┐  │
    │  │- CLIライブラリ                                                                             │  │
    │  │ ┌───────────────────────────────────────────┐ │  │
    │  │ │ - main command module                                                                │ │  │
    │  │ │┌────────────────────────────┐    ┌─────────┐│ │  │
    │  │ ││- メインプロセス                                        │    │- コマンド        ││ │  │
    │  │ ││  - 状態マシン（システム状態）                          │    │  - ハンドラー管理││ │  │
    │  │ ││  - イベント駆動                                        │─→│  - 登録・削除    ││ │  │
    │  │ ││                                                        │    │                  ││ │  │
    │  │ ││                                                        │    │                  ││ │  │
    │  │ │└────────────────────────────┘    │                  ││ │  │
    │  │ │            ↑                              ↓                  │                  ││ │  │
    │  │ │┌────────────┐    ┌────────────┐    │                  ││ │  │
    │  │ ││- 入力解析              │    │ - コマンドライン更新   │    │                  ││ │  │
    │  │ ││- ラインエディター      │    │   （描画状態の更新）   │    │                  ││ │  │
    │  │ │└────────────┘    └────────────┘    └─────────┘│ │  │
    │  │ └───────────────────────────────────────────┘ │  │
    │  │                      ↑                                            ↓                      │  │
    │  │ ┌────────────────────┐  ┌────────────────────┐ │  │
    │  │ │ - Input Interface                      │  │ - Output Interface                     │ │  │
    │  │ │   （FIFO）                             │  │                                        │ │  │
    │  │ └────────────────────┘  └────────────────────┘ │  │
    │  └──────────────────────────────────────────────┘  │
    └──────────────────────── ↑ ────────────────────────┘
                                                       │ 入出力インターフェースを使用
    ┌──────────────────────────────────────────────────┐
    │   Driver                                                                                           │
    │   - 通信機能のDriver（シリアル・BLE等...）                                                         │
    └──────────────────────────────────────────────────┘
                                                       ↑
    ┌──────────────────────────────────────────────────┐
    │   Hardware                                                                                         │
    └──────────────────────────────────────────────────┘
```


### 3.3 各コンポーネントの責務

CLIライブラリに定義するコンポーネントは、明確に分離された責務を持ちます。

| コンポーネント名       | 概要                                                   | 設計上の制約・ルール（依存ルール） |
| ---------------------- | ------------------------------------------------------ | ---------------------------------- |
| `main command module`  | ・CLIシステムの全体制御・コマンドの制御基盤            | ・Applicationが利用するコンポーネントである |
| `Input Interface`      | ・コマンドラインを成形するデータ入力                   | ・通信フォーマット等の解析は責務外、データ本体（文字データ）のみを入力すること |
| `Output Interface`     | ・最新のコマンドラインを描画するための文字・文字列出力 | ・出力用のバッファ領域は持たないため、必要に応じてDriver側での制御を要求する |


### 3.4 依存関係

#### `main command module`

Application層が使用するコンポーネントとして定義されています。

```text
    ┌───────────────────────────┐
    │ - Application                                        │
    └───────────────────────────┘
                                ↓
    ┌───────────────────────────┐
    │ - CLIライブラリ                                      │
    │ ┌────────────────────────┐ │
    │ │ - main command module                          │ │
    │ └────────────────────────┘ │
    └───────────────────────────┘
```

#### `Input Interface`

Driver層に入力された文字・文字列をCLIライブラリに送信するコンポーネントとして定義されています。

```text
    ┌───────────────────────────┐
    │ - CLIライブラリ                                      │
    │ ┌────────────────────────┐ │
    │ │ - Input Interface                              │ │
    │ └────────────────────────┘ │
    └─────────────↑─────────────┘
                                │
    ┌───────────────────────────┐
    │ - Driver                                             │
    └───────────────────────────┘
```

#### `Output Interface`

コマンドラインの描画状態を更新するため、CLIライブラリ自身、またはアプリケーションが使用するコンポーネントとして定義されています。

```text
    ┌───────────────────────────┐
    │ - CLIライブラリ                                      │
    │ ┌────────────────────────┐ │
    │ │ - main command module                          │ │
    │ └────────────────────────┘ │
    │            ↑                          ↓            │
    │ ┌──────────┐    ┌──────────┐ │
    │ │ - Input Interface  │    │ - Output Interface │ │
    │ └──────────┘    └──────────┘ │
    └──────↑─────────────│──────┘
                  │                          ↓
    ┌───────────────────────────┐
    │ - Driver                                             │
    └───────────────────────────┘
```

公開APIを使用することでアプリケーションからの操作も可能です。

```text
    ┌───────────────────────────┐
    │ - Application                                        │
    └───────────────────────────┘
                                │
    ┌─────────────│─────────────┐
    │ - CLIライブラリ          ↓                          │
    │ ┌────────────────────────┐ │
    │ │ - Output Interface                             │ │
    │ └────────────────────────┘ │
    └─────────────│─────────────┘
                                ↓
    ┌───────────────────────────┐
    │ - Driver                                             │
    └───────────────────────────┘
```


### 3.5 設計方針

CLIライブラリは、特定の動作環境に依存しない再利用可能なソフトウェアとして設計します。

ユーザはCLIライブラリの内部構造を理解していなくても、ユーザ自身が定義したコマンドを介してアプリケーションの操作やデバッグ等の機能を実現します。

- マルチインスタンスに対応すること
- インスタンス生成用の公開データは不透明型を採用すること
- 入出力デバイスへの依存
- 動的メモリは使用しない
- 内部バッファ等のリソース消費サイズはユーザが定義可能な設計を行うこと
- リアルタイムOS必須ではない

## 4. 制御設計
### 4.1 全体フロー

本ソフトウェアは、初期化処理の完了後に通常動作可能な状態に遷移します。

通常動作時は、データの入力状態に応じてユーザ定義コマンドの実行が可能です。

機器本体の電源OFFや、アプリケーションがCLIの終了を要求した場合はそのリソースを解放します。

```text
    ┌──────────┐
    │     CLI初期化      │
    └──────────┘
               │ 初期化成功時、システムは通常動作状態に遷移する
               ↓
    ┌──────────┐
    │    通常動作状態    │
    └──────────┘
               │ 電源OFF、または初期化解除によってCLIは終了する
               ↓
    ┌──────────┐
    │     初期化解除     │
    └──────────┘
```

### 4.2 初期化

CLIライブラリの動作設定や、ユーザ定義コマンドの登録は初期化時に行います。

```text
    ┌──────────┐
    │     初期化開始     │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │   インスタンスの   │
    │    メモリ初期化    │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │  ユーザ設定を反映  │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │ ユーザ定義コマンド │
    │        登録        │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │     初期化終了     │
    └──────────┘
```

### 4.3 通常動作

コンソールに入力したコマンドは通信機能を介してCLIに渡されます。

CLIはコマンドに応じてユーザ定義コマンドの起動を要求します。

```text
    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │      Hardware      │    │      通信機能      │    │    CLIライブラリ   │    │    ユーザアプリ    │
    │                    │    │    （Driver層）    │    │  （Middleware層）  │    │  （Application層） │
    └──────────┘    └──────────┘    └──────────┘    └──────────┘
               │                          │                          │                          │           
               │      コマンドを入力      │                          │                          │           
               │────────────→│                          │                          │           
               │                          │        CLIに送信         │                          │           
               │                          │────────────→│    ユーザ定義コマンド    │           
               │                          │                          │         起動要求         │           
               │                          │                          │────────────→│           
               │                          │                          │                          │           
               │                          │                          │         終了通知         │           
               │                          │                          │←────────────│           
               │                          │   コマンドラインの更新   │                          │           
               │                          │←────────────│                          │           
               │        データ出力        │                          │                          │           
               │←────────────│                          │                          │           
               │                          │                          │                          │           
               │                          │                          │                          │           
```

ユーザ定義コマンドのライフサイクルは常に一定ではありません。

例えばコマンドの起動後、継続して実行する必要がある場合はCLIはユーザ定義コマンドの実行状態に遷移します。

このとき、CLIに入力されるコマンドは制限されますので、他のコマンドが実行されることはありません。

```text
    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │      Hardware      │    │      通信機能      │    │    CLIライブラリ   │    │    ユーザアプリ    │
    │                    │    │    （Driver層）    │    │  （Middleware層）  │    │  （Application層） │
    └──────────┘    └──────────┘    └──────────┘    └──────────┘
               │                          │                          │                          │           
               │      コマンドを入力      │                          │                          │           
               │────────────→│                          │                          │           
               │                          │        CLIに送信         │                          │           
               │                          │────────────→│    ユーザ定義コマンド    │           
               │                          │                          │         起動要求         │           
               │                          │                          │────────────→│           
               │                          │                          │                          │           
               │                          │                          │         起動通知         │           
               │                          │                          │←────────────│           
               │                          │                          │                          │──┐     
               │                          │                          │                          │    │ 終了要求がくるまで
               │                          │                          │                          │←─┘ ユーザ定義コマンドは処理を継続
               │    終了コマンドを入力    │                          │                          │           
               │────────────→│                          │                          │           
               │                          │        CLIに送信         │                          │           
               │                          │────────────→│                          │           
               │                          │                          │         終了要求         │           
               │                          │                          │────────────→│           
               │                          │                          │         終了通知         │           
               │                          │                          │←────────────│           
               │                          │   コマンドラインの更新   │                          │           
               │                          │←────────────│                          │           
               │        データ出力        │                          │                          │           
               │←────────────│                          │                          │           
               │                          │                          │                          │           
               │                          │                          │                          │           
```


### 4.4 終了処理

終了処理実行時点の制御データ・システム状態、また登録したユーザ定義コマンドはすべて破棄されます。

```text
    ┌──────────┐
    │    終了処理開始    │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │   インスタンスの   │
    │    メモリ初期化    │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │  ユーザ設定を破棄  │
    │  （コマンド含む）  │
    └──────────┘
               │
               ↓
    ┌──────────┐
    │    終了処理終了    │
    └──────────┘
```

| カーソル移動（右） | 右カーソル　　　　　 |  |  |
| バックスペース　　 | バックスペースキー　 |  |  |
| 履歴参照（新）　　 | 上カーソル　　　　　 |  |  |
| 履歴参照（旧）　　 | 下カーソル　　　　　 |  |  |
| コマンドライン確定 | エンターキー　　　　 |  |  |
| キャンセル　　　　 | Ctrl + c           |  |  |



#### CLI開始
利用開始の要求を受けてイベントが生成される。  
通常の入力データとは異なるイベントとして扱われる。  

#### キャラクタ入力
コマンドラインを構成するデータの入力時にイベントが生成される。  
ラインエディターに分類される。  

#### 履歴参照（新しい or 古い）
カーソルキーの上、または下の入力時にイベントが生成される。  
それぞれ、古い履歴を遡り・新しい履歴に進むの動作を要求する。  
ラインエディターに分類される。  

#### カーソル移動（左右）
カーソルキーの左、または右の入力時にイベントが生成される。  
現在のカーソル位置変更を要求する。
ラインエディターに分類される。  

#### バックスペース
コマンドラインを構成するデータの入力時にイベントが生成される。  
ラインエディターに分類される。  

#### エンター（確定）
エンター（確定）入力時にイベントが生成される。  
コマンドラインの有無にかかわらずイベントは生成され、現在コマンドラインが有するデータの内容に応じてアクションが行われる。  

### キャンセル
`Ctrl + c`の入力によってイベントが生成される。  
イベント生成時の状態に応じて処理が異なるが、現在動作のキャンセル（中止）を行いプロンプトは再描画される。  


### 5.4 イベントフロー

イベント生成時は現在の状態、生成イベントに応じて状態遷移表が発生します。  

- 状態遷移表

| 状態 / イベント | CLI開始   | キャラクタ入力 | 新しい履歴に進む | 古い履歴を遡る | カーソル移動（左） | カーソル移動（右） | バックスペース | エンター（確定）        | キャンセル |
| --------------- | --------- | ------------- | -------------- | ------------- | ---------------- | ----------------- | ------------ | ---------------------- | --------- |
| 稼働準備　      | 通常稼働中 | - | - | - | - | - | - | - | - |
| 通常稼働中      | -         | 通常稼働中     | 通常稼働中      | 通常稼働中    | 通常稼働中         | 通常稼働中        | 通常稼働中     | 通常稼働中 / 実行稼働中 | 通常稼働中 |
| 実行稼働中      | -         | - | - | - | - | - | - | - | 通常稼働中 |
| 異常　　　      | -         | - | - | - | - | - | - | - | - |

公開ヘッダには、コマンドに関するデータを宣言します。

```h
/**
 * @brief コマンドのreturnコード
 */
typedef enum
{
    CLI_COMMAND_CODE_OK,
    CLI_COMMAND_CODE_RUNNING,
    CLI_COMMAND_CODE_SUSPEND,
    CLI_COMMAND_CODE_FAULT
} cli_command_code_t;

/**
 * @brief コマンドハンドラ型
 * @param argc コマンドライン引数の数
 * @param argv コマンドライン引数を格納する文字列配列
 * @return 処理結果
 */
typedef cli_command_code_t (*cli_command_handler_t)(int argc, char **argv);

/**
 * @brief コールバック型
 *        実行中コマンドの停止要求を通知するコールバック型
 * @return 処理結果
 */
typedef cli_command_code_t (*cli_command_callback_t)(void);

/**
 * @brief コマンド定義用データ
 *        ユーザ定義コマンドは本データ構造を使用して定義する。
 * @note
 * 各データは用途を記載します。
 * - name     : コマンドの名称を登録。
 * - notes    : コマンドの説明・注釈を登録。
 * - handler  : コマンド実行要求を受けた際に起動するハンドラ。
 * - callback : コマンドの停止を要求するコールバック。
 * 
 * コマンドを利用するためには、nameとhandlerの登録が必要です。
 * ワンショットで処理が完了する場合、callbackの登録は必ずしも必要ではありません。
 * 強制終了等の割り込みシグナルに応じてコマンドを停止させたい場合に使用します。
 */
typedef struct
{
    /** 定義名称・注釈 */
    const char * name;
    const char * notes;

    /** 通知用インターフェース */
    cli_command_handler_t handler;      /* コマンドハンドラ */
    cli_command_callback_t callback;    /* 停止コールバック */
} cli_command_t;
```

登録用インターフェースを使用して、コマンド定義用データはCLIライブラリに渡されます。

| 名称                   | 概要               | 説明  |
| ---------------------- | ------------------ | ----- |
| cli_command_register   | コマンド登録       | `cli_command_t`の型を使用したコマンドをCLIライブラリに登録します。 |
| cli_command_unregister | コマンド登録解除　 | `cli_command_register`によって登録されたコマンドの登録解除を行います。 |
